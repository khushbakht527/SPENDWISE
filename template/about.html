About Application

Overview

This Personal Expense Tracker helps users record and categorize everyday spending, manage wallet balances, and monitor savings with clean visualizations and simple controls.

Key Features

  • Track daily and weekly expenses with optional dates.
  • Manage wallet balance and monthly savings easily.
  • Interactive charts to analyze spending by category.
  • Per-user persistence (server + local cache) for resilience.

How It Works

Sign up or log in, add funds to your wallet, and log expenses. The dashboard updates totals and charts in real time and stores your data so you can return later.

Data & Privacy

For this demo data is stored in a local JSON file on the server. For production use a secure database and proper authentication; personal data is not shared by this app.

Built With

Flask (Python), Chart.js, HTML, CSS and JavaScript — lightweight and easy to extend.
